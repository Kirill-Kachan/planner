- docs/MEMORY.md: статус, решения, баги. Читай первым.
- docs/PRD.md, docs/ARCHITECTURE.md, docs/RULES.md (обязательны), docs/DESIGN.md (не придумывай стиль), docs/TASKS.md (одна задача за раз).
## Порядок работы
1. Прочитай MEMORY и TASKS, назови задачу.
2. Изучи затронутые функции в index.html, дай короткий план.
3. Проверь, нет ли подходящего навыка (skill) под задачу (например frontend-design для UI).
4. Маленькое изменение; перед деплоем `node --check` для скриптов.
5. Коммит в main (деплой Netlify автоматически), обнови TASKS и MEMORY, скажи как проверить.
