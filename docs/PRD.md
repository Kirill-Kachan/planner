# PRD — «Планы»

**Версия:** 1.x · **Статус:** в эксплуатации, дорабатывается · **Сайт:** https://planner-go.netlify.app/

## 1. Обзор
Личный мобильный планировщик в виде PWA (ярлык на домашнем экране iPhone). Один человек, один телефон, без регистрации и сервера. Всё хранится на устройстве.

## 2. Проблема
Задачи, тренировки, обслуживание машины и мысли разбросаны по разным приложениям. Нужен один быстрый инструмент, который работает офлайн и считает динамику тренировок.

## 3. Цели
- Быстро добавлять и закрывать задачи.
- Вести тренировки и видеть прогресс (вес, повторы, объём) относительно прошлой такой же тренировки.
- Вести задачи и историю обслуживания авто.
- Не терять данные (резервные копии).

## 4. Пользователь
Один владелец. iPhone, Safari / PWA с домашнего экрана. Язык интерфейса — русский. Часто работает без сети.

## 5. Функции (текущие)
1. **Задачи:** категории, приоритеты, дедлайны, подзадачи, статусы, напоминания.
2. **Спорт:** типы тренировок (настраиваемые, SVG-иконки), упражнения (обычные, разный вес/повторы, лесенка), карточки по неделям, динамика (стрелка ↑/↓), «Пред:» из прошлой тренировки.
3. **Авто:** задачи, история обслуживания (километраж, дата, заметки).
4. **Заметки и идеи:** свободное письмо, объединённый раздел.
5. **Статистика:** выполненные задачи (год→месяц→неделя→день), по мышцам и по упражнениям (поиск, история, динамика).
6. **Настройки:** 11 тем, погода, резервная копия (скачать/загрузить), сброс тренировок, Notion-синхронизация (не используется).
7. **Офлайн:** service worker (`sw.js`), работает без сети и при слабом интернете.
8. **Платежи:** календарь день/неделя/месяц, повтор (неделя/месяц/год), отметка «оплачено».
9. **Жду ответа:** от кого, что, этап процесса, дни ожидания, история этапов (блок на экране задач).
10. **Прозрачность:** ползунки прозрачности и размытия в настройках.

## 6. Вне рамок
- Бэкенд, аккаунты, синхронизация между устройствами.
- Нативное приложение из App Store.
- Совместная работа.
