## 2026-11-23 — Форма тренировки: один подход по умолчанию
- Новая тренировка из прошлой того же типа: у каждого упражнения 1 пустой подход (раньше — столько же, сколько в прошлой). «＋ Подход» копирует значения последнего подхода. «↺ Подставить значения прошлой» добавляет недостающие подходы сама.

## 2026-11-24 — Шапка «Сегодня»: дата + город и погода, тихая погода
- Шапка как в референсе (Bevel): «Сегодня» / крупная дата «24 нояб.» / строка «Город, регион · значок температура». Тап по дате — на сегодня, тап по строке погоды — принудительно обновить место и погоду.
- Погода и место кэшируются в localStorage `pln6_wx` (temp, icon, city, geo): при открытии показывается сразу, обновляется тихо, без уведомлений об ошибках. Город — reverse-geocode bigdatacloud (без ключа), погода — open-meteo; ночью значок 🌙.
- Геолокация: новый запрос координат только если разрешение уже `granted` (без диалога) или кэша ещё нет. Ограничение iOS: в режиме «на экран Домой» Safari может спрашивать разрешение заново при запуске — обойти из веб-приложения нельзя. Если спрашивает каждый раз: Настройки → Конфиденциальность → Службы геолокации → Safari/Веб-сайты → «При использовании».

## 2026-11-24 — Полный экран под статус-баром
- Причина большого пустого места сверху: без `viewport-fit=cover` iOS сам отступал под статус-бар (~54pt), плюс наш `.ph{padding-top:52px}`. Теперь `viewport-fit=cover` + `.ph` padding = `max(env(safe-area-inset-top),20px)+10px`; приложение рисуется под временем и батареей, сверху фиксированный мягкий градиент цвета фона (`body::before`), чтобы текст при прокрутке не сливался со статус-баром.
- Если на устройстве вид не изменился: закрыть приложение смахиванием и открыть заново (для иконки на «Домой» мета-тег читается при запуске).

## 2026-11-24 — Полный экран: низ
- Баг: после `viewport-fit=cover` снизу оставалась чёрная полоса (body с `height:100%` не занимал нижнюю безопасную зону). Фикс: `body{position:fixed;top:0;bottom:0;left:0;right:0}`; нижняя панель, «＋» и отступ списка учитывают `--sab` (= `env(safe-area-inset-bottom)`, коэффициенты .45/.55, чтобы панель не лежала на «полоске» Home).
