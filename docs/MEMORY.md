## 2026-11-23 — Форма тренировки: один подход по умолчанию
- Новая тренировка из прошлой того же типа: у каждого упражнения 1 пустой подход (раньше — столько же, сколько в прошлой). «＋ Подход» копирует значения последнего подхода. «↺ Подставить значения прошлой» добавляет недостающие подходы сама.
