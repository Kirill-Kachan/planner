# RULES — правила для Claude

- Следуй PRD, ARCHITECTURE, DESIGN. Маленькие изменения, одна задача за раз.
- Не трогай то, что не связано с задачей. Сначала ищи существующую логику, не дублируй.
- Без новых библиотек и сборки: ванильный JS в одном `index.html`.
- Вспомогательные функции — в глобальной области, не внутри `pgXxx`.
- Даты только локальные (`getFullYear/getMonth/getDate`), не `toISOString`. Неделя Пн–Вс.
- Ключ данных `pln6` не менять без миграции. Никогда не терять данные пользователя.
- Перед каждым деплоем: достать `<script>`, проверить `node --check`.
- Деплой: коммит в `main` → Netlify. После деплоя сказать, как проверить (закрыть и открыть приложение).
- Никаких токенов и ключей в коде и документах.
- Не советовать удалять ярлык с экрана. Перед любыми рискованными действиями — «⬇️ Скачать копию».
- Каждый запрос/операцию с данными оборачивать в try/catch, пользователю — понятный toast.
- После задачи обновить `docs/TASKS.md` и `docs/MEMORY.md`.
- Общаться по-русски, коротко, без лекций.
