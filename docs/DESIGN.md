# DESIGN

Источник правды — CSS-переменные в `index.html`. Новые цвета и размеры сначала сюда, потом в код.

## Цвета (тёмная тема по умолчанию)
| Роль | Переменная | Значение |
|---|---|---|
| Фон | `--bg` | #0d0d10 |
| Поверхности | `--bg2` / `--bg3` / `--bg4` | #16161c / #1e1e26 / #26262f |
| Рамки | `--bd` / `--bd2` | rgba(255,255,255,.06 / .12) |
| Текст | `--tx` / `--t2` / `--t3` | #eeeef5 / #8888a0 / #50506a |
| Акцент | `--acc` | #1a8fff |
| Ошибка / приоритет высокий | `--red` | #ff3b50 |
| Внимание | `--yel` | #ffaa00 |
| Успех | `--grn` | #26d467 |
| Фиолетовый | `--pur` | #9b8dff |
Подложки: `--rbg --ybg --gbg --bbg --pbg` (13% прозрачности).

## Темы
Тёмная (по умолчанию), Светлая, Сепия, AMOLED, Океан, Лес, Розовая, Nord, Mocha, Закат, Ночь. Переключаются через `data-theme`, переопределяют только `--bg*`, `--bd*`, `--tx/t2/t3` (и акцент).

## Типографика
Шрифт: Inter, sans-serif. Подписи секций: 10px, 800, uppercase, `letter-spacing:.09em`, цвет `--t3`. Основной текст 13–16px. Данные прошлых тренировок — крупнее и выделены.

## Радиусы и отступы
`--r:13px` (карточки), `--rs:8px`. Поля страницы 16px (24px на ≥600px). Шкала 4·8·16·24.

## Компоненты
- **Карточка задачи (.tc):** полоска слева 3px цвета приоритета (красный/жёлтый/зелёный/синий), чекбокс 20px.
- **Нижняя панель:** скруглённая, «стеклянная» (backdrop-filter + непрозрачный фон > 0, `translateZ(0)`), крупные кнопки-виджеты, высота `--nav-h:80px`.
- **Кнопка «+»:** на одном месте во всех разделах.
- **Иконки:** единый современный SVG-стиль, не эмодзи (эмодзи только в превью тем).
- **Динамика тренировок:** ↑ зелёная, ↓ красная.
- **Категории:** без цветных точек (чтобы не конфликтовать с приоритетами).

## Тон
Спокойный, iOS-подобный, компактный, читаемый «на ходу». Без пёстрых цветов.
